# BlogDeCafé

BlogDeCafé es un sitio web estático dedicado al mundo del café. Incluye artículos, información sobre cursos, una página institucional y un formulario de contacto con validación desde el navegador.

El proyecto está pensado como una página informativa sencilla, clara y responsive, ideal para practicar estructura HTML, estilos CSS y pequeñas interacciones con JavaScript.

## Vista General

- Diseño adaptable para escritorio, tablet y móvil.
- Navegación entre páginas internas.
- Contenido sobre café, recetas, granos y cursos.
- Formulario de contacto con campos requeridos.
- Imágenes optimizadas en formato JPG y WebP.
- Código organizado por carpetas.

## Páginas del Sitio

- `index.html`: página principal con entradas del blog y cursos destacados.
- `nosotros.html`: presentación del proyecto y su propósito.
- `cursos.html`: listado de cursos y talleres disponibles.
- `entrada.html`: artículo sobre tipos de grano de café.
- `contacto.html`: formulario para mensajes o reservas de cursos.

## Cómo Ejecutar el Proyecto

Puedes abrir el proyecto de dos formas:

1. Abre el archivo `index.html` directamente en el navegador.
2. Coloca la carpeta dentro de `htdocs` y ejecútala desde XAMPP/Apache.

Ejemplo con XAMPP:

```text
http://localhost/proyectosWeb/blogdecafe/
```
